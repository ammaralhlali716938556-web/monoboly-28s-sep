# 🎲 Tactile Toymorphism 3D Board Game

نموذج أولي تفاعلي للعبة لوحية ثلاثية الأبعاد مبنية بنمط **Tactile Toymorphism** (المزيج بين Low-Poly الكرتوني، خامات PBR الواقعية الملموسة للبلاستيك والمعادن، مع واجهات كاجوال Juicy UI).

## 🚀 تشغيل اللعبة عبر GitHub Pages في دقيقة واحدة:

1. أنشئ مستودعاً جديداً على [GitHub](https://github.com/) واجعله **Public**.
2. ارفع هذه الملفات بنفس المسارات الموضحة أعلاه إلى الفرع `main`.
3. اذهب إلى إعدادات المستودع: **Settings** ➡️ **Pages**.
4. تحت خيار **Build and deployment**، اضبط **Source** على: **GitHub Actions**.
5. سيقوم ملف `main.yml` ببناء اللعبة وتزويدك برابط مباشر للعب على هاتفك أو متصفحك فوراً!
